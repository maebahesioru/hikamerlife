# 2万分の1のヒカマー v3

時代・経緯・環境をくじで引いてヒカマーとして参入し、**1日ずつ**界隈歴を生きて、**引退**までを体験するブラウザゲーム。
ヒカマー界隈の実データ・実史（Wiki・810ch・Hikabooru・名乗り調査・人口検査）をベースにしたキャリア・シミュレーション。

- **本番URL**: https://hikamerlife.hikamers.app/
- 構成: 素のHTML/CSS/JS（ビルド不要） + nginx:alpine（Coolifyデプロイ）
- v3ボリューム: イベント**196種**・決断**93種**・図鑑**130種**・称号**42種**・終わり方**11種**・重点**12種**・家**11種**・ネット環境**11種**・参入経緯**3種**・きっかけ**6種**・仲間アーク12種
- 参考にした作品: [80億分の1](https://1in8b.life/ja/) / [1.2億分の1](https://1in120m.uxwxu.com/) / [100万分の1(富山)](https://nurie.xyz/1in1m-toyama/) / [人間に生まれる確率](https://yoshitakeapp.com/games/next-life-gacha/) / [日本に生まれる](https://nihonjin.iniminigen.com/)

## 使い方（クイックスタート）

1. トップで「くじを引いて参入する」を押す（名前・ハンドル・性別・**時代**・**年齢**・**参入の経緯（新規/転生復活/他界隈から）**・**きっかけ**は任意。「あなた自身」欄に実際の参入年・年齢を入れると結果で比較される）
2. **1日ずつ**進む。**⏸一時停止／▶再開**、**⏩次の出来事まで**、×1〜×8速度、「おまかせ」で放置も可
3. 「重点」（馴れ合い／制作／制裁・監視／ROM／現実優先／政治・時事／アルカイダ／開発叩き／道具づくり／拡散営業／凸・オフ活動の12種）を切り替えると日々の伸び方・リスクが変わる
4. **終わりは死亡ではなく引退**（自主引退・静かな消滅・卒業・界隈を去る・心が折れた・長すぎた界隈歴・垢ごと消えた・新天地へ・幽霊・おやすみ・燃え尽きの11種）。称号・希少度・共有カードが出る。**記録は「リアル側」「ネット側」に分けて表示**され、同時期の参入組のその後も並ぶ
5. 「メモリアル」に納めると端末に残る。ろうそく、「もう一度見る」で過去記録の再表示（カードも再生成・保存できる）
6. 出会った語録・文化・事件・時代は「図鑑」に貯まる（★を付けた行はエンディングの「心に残る行」に優先表示）

## ステータス

- **基礎**: 体調 / 幸福 / 学業・仕事 / 人間関係 / メンタル
- **ヒカマー**: フォロワー / 語録力 / 技量 / 特定リスク / 凍結リスク
- 隠し値: 熱量（活動の温度）/ 馴れ合い度・過激さ・開発叩き度（称号と一部イベントに影響）

## しくみ（要約）

- 1回の界隈歴はシード付き乱数で決定的。**時代（2019〜2026）**・**参入時年齢（12〜18歳）**・都道府県・家・ネット環境はくじ
- 日次ループ: 熱量の増減 → フォロワー成長（実力由来の天井つき）→ リスク蓄積 → イベント抽選（暦イベント＋一般プール）→ 節目（30/100/365日…）→ 決断（約9日クールダウン）
- 継続曲線は e^(−日数/550)（界隈の平均寿命「2〜3年」を近似）。多くの界隈歴は1〜2年で終わり、長寿は「化石」になる
- 特定は「住所特定祭り」の季節（3〜4月・9〜10月）に、高リスク時のみ発生
- 確率チェーン（日本に生まれる1/66.7〜）は**表示された数字の積＝合計**になるように丸めてある

### v3.2（2026-10-16）本家の「途中で閉じても、続きから」を移植

本家は `save()`（91309行）/`restore()`（91331行）＋`SAVE_KEY` でライフ途中状態を永続化し、出生証明書にも「途中で閉じても…続きから生きられます」と書いている。うちに無かった機能:

- **自動保存**: 10日ごと ＋ ⏸一時停止時 ＋ pagehide/visibilitychange（タブを閉じる・隠すとき）
- **つづきから**: スタート画面にボタン（`@ハンドル・Day ◯・◯◯年`）。RNGは mulberry32 の32bit状態 `_a` を保存し、復元後の乱数列が**完全一致**するのをテスト済み（resume determinism: true）
- 新規開始時は上書き確認（confirm）、エンディングでセーブは自動削除
- **あなたの部屋シーン**: キャンバス描画。機材が成長（スマホ→ノート→自作PC→デュアルモニタ＋マイク）、壁に記録カード（フォロワー10/100/1,000/1万の4段階）＋1万で金の星飾り、深夜/昼下がりの切り替え、画面の照り返し・リムライト・接地影

### v3.3（2026-10-16）みんなのメモリアル（公開サーバー）

本家の中核ソーシャル機能（`openMemorial`・`/api/memorial(s)`・`/api/react` 系: みんなの人生を見る・ろうそく）に対応する**サーバー共有メモリアル**を実装。

- **API**: Cloudflare Workers + KV（無料枠）。エンドポイント: `POST /api/mem`（公開）・`GET /api/mems`（最新30件）・`POST /api/candle`（ろうそく）
- 場所: `hikamerlife.hikamers.app/api/*` を Workers ルートで処理（トンネルより手前で受ける）
- 入力はゲーム生成値のみ（ハンドル・称号・日数・時代・終わり方など。各フィールド長さ制限＋タグ除去）。フリーテキストの公開はなし（ひとことはローカルのみ）
- 公開はエンディングの「みんなのメモリアルに残す」（確認ダイアログ付き・匿名）
- KVは結果整合（書き込みが見えるまで最大60秒かかることがある）→ 投稿直後のトーストにその旨を明記
- メモリアル画面はタブ式: 「あなたの記録」（ローカル＋これまでのまとめ行）／「みんなのメモリアル」
- 検証: smoke8（ローカル→本番API）・smoke9（本番フル: 公開→一覧→ろうそく）全PASS・エラー0
