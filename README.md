# 4万分の1のヒカマー v2

時代をくじで引いてヒカマーとして参入し、**1日ずつ**界隈歴を生きて、**引退**までを体験するブラウザゲーム。
ヒカマー界隈の実データ・実史（Wiki・810ch・Hikabooru・人口検査）をベースにしたキャリア・シミュレーション。

- **本番URL**: https://hikamerlife.hikamers.app/
- 構成: 素のHTML/CSS/JS（ビルド不要） + nginx:alpine（Coolifyデプロイ）
- 参考にした作品: [80億分の1](https://1in8b.life/ja/) / [1.2億分の1](https://1in120m.uxwxu.com/) / [100万分の1(富山)](https://nurie.xyz/1in1m-toyama/) / [人間に生まれる確率](https://yoshitakeapp.com/games/next-life-gacha/) / [日本に生まれる](https://nihonjin.iniminigen.com/)

## 使い方（クイックスタート）

1. トップで「くじを引いて参入する」を押す（名前・ハンドル・性別・**時代**・**年齢**は任意）
2. **1日ずつ**進む。決断が来たら選ぶ。「⏩ 次の出来事まで」で早送り、×1〜×8で速度、「おまかせ」で放置も可
3. 「重点」（馴れ合い／制作／制裁・監視／ROM／現実優先）を切り替えると日々の伸び方・リスクが変わる
4. **終わりは死亡ではなく引退**（自主引退・静かな消滅・卒業・界隈を去る・心が折れた・長すぎた界隈歴）。称号・希少度・共有カードが出る。カードはPNG保存できる
5. 「メモリアル」に納めると端末に残る。ろうそく、「もう一度見る」で過去記録の再表示
6. 出会った語録・文化・事件・時代は「図鑑」に貯まる（★を付けた行はエンディングの「心に残る行」に優先表示）

## ステータス

- **基礎**: 体調 / 幸福 / 学業・仕事 / 人間関係 / メンタル
- **ヒカマー**: フォロワー / 語録力 / 技量 / 特定リスク / 凍結リスク
- 隠し値: 熱量（活動の温度）/ 馴れ合い度・過激さ・開発叩き度（称号と一部イベントに影響）

## しくみ（要約）

- 1回の界隈歴はシード付き乱数で決定的。**時代（2019〜2026）**・**参入時年齢（12〜18歳）**・都道府県・家・ネット環境はくじ
- 日次ループ: 熱量の増減 → フォロワー成長（実力由来の天井つき）→ リスク蓄積 → イベント抽選（暦イベント＋一般プール）→ 節目（30/100/365日…）→ 決断（約9日クールダウン）
- 継続曲線は e^(−日数/550)（界隈の平均寿命「2〜3年」を近似）。多くの界隈歴は1〜2年で終わり、長寿は「化石」になる
- 特定は「住所特定祭り」の季節（3〜4月・9〜10月）に、高リスク時のみ発生
- 確率チェーン（日本に生まれる1/66.7〜）は**表示された数字の積＝合計**になるように丸めてある

## 人口検査（2026-10-15・「4万分の1」は本当か）

3つの独立サンプルの**捕獲再捕獲法（Lincoln-Petersen）**で推定:

| サンプル | サイズ | 重複 | 推定 |
|---|---|---|---|
| フォロワーネットワーク深掘り（9/25） × Yahoo!リアルタイム検索（10/15） | 409 × 29 | 9 | **N ≈ 1,318** |
| 同上 × 界隈横断コーパス（167,276文書スキャン） | 409 × 149 | 33 | **N ≈ 1,847** |
| Yahoo × コーパス | 29 × 149 | 1 | N ≈ 4,321（不安定・参考） |

**結論: 活動中ヒカマー ≈ 1,300〜4,300人（代表値2,500）。日本のネット人口 約1億人 ÷ 2,500 ≒ 4万分の1（幅2万〜10万分の1）。**
「_mania」サフィックス限定・海外除外・活動中定義依存などの限界つき。レポート: `~/ダウンロード/hikamer_life_research/人口精密検査レポート_20261015.md`

## 開発

```bash
# ローカル
cd site && python3 -m http.server 8899

# バランス検証（ヘッドレス・v2）
node test/sim2.js 300 random    # ランダム戦略
node test/sim2.js 200 sakusei   # 制作重点
node test/sim2.js 150 nareai    # 馴れ合い重点
node test/sim2.js 150 real      # 現実優先

# 実測テスト（Playwright, c4-env）
~/c4-env/bin/python ~/ダウンロード/hikamer_life_research/test_game2.py [URL]
```

- `site/js/data2.js` — 時代・重点・称号・図鑑・人口検査値
- `site/js/events2.js` — 暦イベント/一般イベント/決断
- `site/js/extra2.js` — 増量パック（追加イベント・決断・称号・図鑑）
- `site/js/engine2.js` — 日次エンジン（時代くじ/熱量/成長/リスク/節目/引退エンド）
- `site/js/ui2.js` — 画面・重点・★・スキップ・エンディング・共有カード・図鑑/メモリアル
- `site/js/*.js`（v1: data/events/engine/ui）— 旧版。index.htmlからは読み込んでいない
